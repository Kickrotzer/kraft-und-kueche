# Kraft und Küche

Kleine Handy-App für Training, Protein, Wasser, Fastenfenster, Gerichte, Einkaufsliste und Gewichtsverlauf.

Eine einzige Datei (`index.html`), keine Abhängigkeiten. Daten bleiben lokal im Browser des Handys (localStorage).

## Auf dem Handy nutzen

1. Repo auf GitHub, dann Settings, Pages, Branch `main`, Ordner `/ (root)`.
2. Die Seite unter `https://<benutzername>.github.io/<repo>/` am Handy öffnen.
3. iPhone: Teilen, Zum Home-Bildschirm. Android: Menü, App installieren.
